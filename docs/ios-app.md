# Vocla for iOS

The iOS app is the same app as the web version, wrapped in a native shell with [Capacitor](https://capacitorjs.com). There's one codebase, so desktop, web and iPhone always behave the same.

What the native shell adds over the web version:

| | Web / Home Screen app | iOS app |
|---|---|---|
| Haptics | hidden-switch workaround (iOS 18+) | real Taptic Engine (light tap on reveal/answer, success/error in lessons) |
| Export | browser download | iOS share sheet (Save to Files, AirDrop, Mail…) |
| Scrolling | whole page scrolls | fixed app shell, only the content pane scrolls (no page rubber-banding) |
| Fonts | bundled | bundled, fully offline |
| Status bar / launch | meta tags | native light status bar, dark launch screen, app icon |
| Saving | debounced to IndexedDB | also saved when the app goes to the background |
| Orientation | any | iPhone: portrait; iPad: any |

Your data lives in the app's own storage on the device. Export a backup from **More → Export** now and then.

## Build and run (needs a Mac)

You need macOS with **Xcode 16+** and Node 22.

```sh
npm install
npm run ios          # builds the web app, copies it into ios/, opens Xcode
```

In Xcode:

1. Select the **App** target → **Signing & Capabilities** → choose your Team (a free Apple ID works for your own phone).
2. If Xcode says the bundle identifier is taken, change it, e.g. to `com.yourname.vocla`. Then change `appId` in `capacitor.config.ts` to match.
3. Pick your iPhone (connected by cable, or on the same Wi-Fi) or a Simulator, then press **Run ▶**.

The first time you run it on a phone: **Settings → General → VPN & Device Management → trust your developer certificate**.

After changing the web code, run `npm run ios:sync` and press Run again.

## No Mac?

- **Check that it builds:** `.github/workflows/ios.yml` builds the app for the iOS Simulator on GitHub's macOS runners on every push. That catches broken builds, but it can't put the app on your phone.
- **Install on your phone without a Mac:** use a cloud build service that signs iOS apps (e.g. Codemagic, Ionic Appflow, Expo EAS for custom builds). You'll need an Apple Developer account ($99/year) for TestFlight or the App Store.
- **Quickest way to try it:** the Home Screen web app. Host `dist/` anywhere (Netlify, GitHub Pages…), open it in Safari, then **Share → Add to Home Screen**. You get the same UI, but the web version of haptics and export.

## App Store checklist

- Apple Developer Program membership.
- A unique bundle id (`appId`) and an App Store Connect record.
- Version numbers: **Marketing Version** and **Build** in Xcode (target → General).
- Screenshots (6.9" and 6.5" iPhone, and 13" iPad if you keep iPad support), a privacy policy URL, and the App Privacy answers. Vocla keeps everything on the device and collects nothing.
- `ITSAppUsesNonExemptEncryption` is already set to `false` in `Info.plist`, so there are no export-compliance questions on each upload.
- Product → Archive → Distribute App → App Store Connect → TestFlight.

## Project layout

- `capacitor.config.ts`: app id/name, web view behaviour, splash and status bar.
- `src/lib/native.ts`: the bridges to native features (each one falls back to the web behaviour in a browser).
- `ios/`: the generated Xcode project. Edit icons in `ios/App/App/Assets.xcassets` and app settings in `ios/App/App/Info.plist`. `ios/App/App/public` is generated by `cap sync` and not committed.
